# 🌿 HappyTrails

### Plan your journey, enjoy the adventure.

HappyTrails is a travel route optimization web app that helps users plan trips efficiently by finding the best route between multiple destinations.

Using the **Travelling Salesman Problem (TSP)** algorithm, it reduces unnecessary backtracking and provides an optimized travel sequence with distance, time, and interactive map visualization.

🔗 **Live Demo:** https://your-netlify-link.netlify.app/

---

## ✨ Features

- 📍 **Route Optimization**
  - Finds the most efficient visiting order for multiple destinations.

- 🔎 **Location Search**
  - Search and select places with autocomplete suggestions.

- 🗺️ **Interactive Map**
  - Visualize optimized routes with markers and route paths.

- ⏱️ **Distance & Time Calculation**
  - Calculates total travel distance and estimated journey duration.

- 🚗 **Google Maps Navigation**
  - Open the optimized route directly in Google Maps.

- 📱 **Responsive Design**
  - Optimized for desktop and mobile devices.
